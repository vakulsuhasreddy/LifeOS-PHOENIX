LifeOS – Your Life. Your Data. Your Intelligence.

Team: PHOENIX
Track: 3 – Know Thyself
Event: wHACKiest 2026

Problem Statement

Personal data is fragmented across smartphones, smartwatches, fitness trackers and other applications. Users often struggle to understand patterns in their daily habits and activities because their data is scattered across different platforms.

Proposed Solution

LifeOS is a privacy-focused personal intelligence platform that converts user-approved personal data into understandable patterns, interactive visualizations and explainable insights.

Key Features

- CSV data upload and validation
- Personal habit journal
- Interactive trend dashboards
- Weekly summaries
- Explainable AI-powered insights
- Privacy, export and delete controls

Technology Stack

- Python
- Streamlit
- Pandas
- NumPy
- Plotly
- SQLite

System Architecture

User Data → Input & Validation → Data Cleaning → Insight Engine → Interactive Dashboard → User Actions

Privacy

LifeOS follows a local-first approach, prioritizing user consent, data ownership and transparency.

Project Status

Early prototype development.
